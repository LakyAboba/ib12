## Конспект лекций: Аналитическая геометрия. Прямая на плоскости

## 1. Семь видов уравнений прямой на плоскости

## I. Уравнение прямой, проходящей через заданную точку перпендикулярно вектору нормали

- Суть: Выводится как геометрическое место точек. Пусть задана точка M₀(x₀, y₀) и ненулевой вектор нормали $\vec{n}(A, B)$, перпендикулярный прямой. Если взять произвольную точку прямой M(x, y), то вектор $\vec{M_0M}(x - x_0, y - y_0)$ должен быть перпендикулярен $\vec{n}$.
- Условие перпендикулярности: Равенство нулю скалярного произведения (сумма произведений координат):  
    $$A(x - x_0) + B(y - y_0) = 0$$
- Важно: Именно этот вывод и уравнение нужно рассказывать на коллоквиуме, если попался соответствующий вопрос.

## II. Общее уравнение прямой

- Если раскрыть скобки в предыдущем уравнении, получится:  
    $$Ax + By + (-Ax_0 - By_0) = 0$$
- Обозначив константу (-Ax₀ - By₀) буквой C, получаем общее уравнение прямой:  
    $$Ax + By + C = 0$$
- Свойство: Из общего уравнения прямой можно мгновенно получить координаты её вектора нормали: $\vec{n}(A, B)$.

## III. Каноническое уравнение прямой

- Суть: Пусть задана точка M₀(x₀, y₀) и ненулевой направляющий вектор $\vec{q}(l, m)$, параллельный прямой. Для любой точки M(x, y) на прямой вектор $\vec{M_0M}$ параллелен (коллинеарен) вектору $\vec{q}$.
- Из условия пропорциональности координат получается канонический вид:  
    $$\frac{x - x_0}{l} = \frac{y - y_0}{m}$$
- Особенность: Если один из знаменателей (l или m) равен 0, это не катастрофа, а показатель того, что прямая параллельна одной из координатных осей (например, если l=0, то прямая параллельна оси Oy, и уравнение означает, что x = x₀).

## IV. Параметрические уравнения прямой

- Если приравнять каноническое уравнение к некоторому параметру t, то выразив x и y, мы получим параметрическую систему:  
    $$\begin{cases} x = x_0 + lt \\ y = y_0 + mt \end{cases}$$
- Применение: Этот вид крайне удобен в математическом анализе для поиска точек пересечения прямой с кривыми (окружность, парабола и т.д.), так как переменные x и y, выраженные через t, легко подставляются в уравнение кривой.

## V. Уравнение прямой в отрезках

- Условие: Применяется для прямых, не проходящих через начало координат. Обозначим точки пересечения прямой с осями координат как A(a, 0) и B(0, b).
- Уравнение выглядит так:  
    $$\frac{x}{a} + \frac{y}{b} = 1$$
- Геометрический смысл: Величина a — это координата (расстояние с учетом знака) до точки пересечения с осью Ox, а b — с осью Oy.

## VI. Уравнение прямой с угловым коэффициентом

- Классический школьный вид, выражающий зависимость y от x:  
    $$y = kx + b$$
- Где $k = \tan\alpha$ (угловой коэффициент), а b — свободный член.

## VII. Нормальное уравнение прямой

- Суть: Из начала координат опускается перпендикуляр на прямую длиной p (расстояние до прямой). Этот перпендикуляр образует с положительными направлениями осей углы α и β. За нормаль принимается единичный вектор $\vec{n}(\cos\alpha, \cos\beta)$.
- Нормальное уравнение имеет вид:  
    $$x\cos\alpha + y\cos\beta - p = 0$$
- Преобразование общего уравнения в нормальное: Чтобы перевести общее уравнение Ax + By + C = 0 в нормальное, его нужно умножить на нормирующий множитель:  
    $$M = \frac{-\text{sign}(C)}{\sqrt{A^2 + B^2}}$$  
    _(Знак перед корнем берется противоположным знаку коэффициента C, чтобы расстояние p в итоге получилось со знаком минус)_.

## 2. Взаимное расположение двух прямых

Пусть даны две прямые:

1. L₁: A₁x + B₁y + C₁ = 0 (вектор нормали $\vec{n_1}(A_1, B_1)$)
2. L₂: A₂x + B₂y + C₂ = 0 (вектор нормали $\vec{n_2}(A_2, B_2)$)

Для определения их взаимного расположения анализируют пропорциональность коэффициентов:

|Соотношение коэффициентов|Геометрический результат|
|---|---|
|$\frac{A_1}{A_2} \neq \frac{B_1}{B_2}$|Прямые пересекаются (векторы нормалей не коллинеарны)|
|$\frac{A_1}{A_2} = \frac{B_1}{B_2} \neq \frac{C_1}{C_2}$|Прямые параллельны|
|$\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$|Прямые совпадают|

- Угол между прямыми: Определяется через угол между их векторами нормалей ($\vec{n_1}$ и $\vec{n_2}$) или направляющими векторами через формулу косинуса скалярного произведения. В вузовском курсе знак угла (острый или тупой) не играет такой жесткой роли, как в школе.

## 3. Расстояние от точки до прямой

- Для нахождения расстояния от точки M₀(x₀, y₀) до прямой, заданной общим уравнением Ax + By + C = 0, используется формула:  
    $$d = \frac{\vert{}Ax_0 + By_0 + C\vert{}}{\sqrt{A^2 + B^2}}$$
- Если использовать нормальное уравнение прямой, то отклонение точки вычисляется простым подставлением координат в уравнение: $d = \vert{}x_0\cos\alpha + y_0\cos\beta - p\vert{}$. Если точка и начало координат лежат по разные стороны от прямой — значение под модулем будет положительным, если по одну сторону — отрицательным.
