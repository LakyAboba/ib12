# Формула Тейлора. Ряды Маклорена. Необходимое условие экстремума

## 1. Формула Тейлора для многочлена

Любой многочлен степени $n$ по степеням $x$:

$$
P_n(x) = b_0 + b_1 x + b_2 x^2 + \dots + b_n x^n = \sum_{k=0}^{n} b_k x^k
$$

можно разложить по степеням $(x - x_0)$ для произвольного числа $x_0$:

$$
P_n(x) = a_0 + a_1 (x - x_0) + a_2 (x - x_0)^2 + \dots + a_n (x - x_0)^n = \sum_{k=0}^{n} a_k (x - x_0)^k.
$$

**Нахождение коэффициентов $a_k$:**
Последовательно дифференцируя равенство и подставляя $x = x_0$:
- $P_n(x_0) = a_0 \implies a_0 = P_n(x_0)$;
- $P_n'(x_0) = 1 \cdot a_1 \implies a_1 = \dfrac{P_n'(x_0)}{1!}$;
- $P_n''(x_0) = 1 \cdot 2 \cdot a_2 \implies a_2 = \dfrac{P_n''(x_0)}{2!}$;
- $\dots$
- $P_n^{(k)}(x_0) = k! \cdot a_k \implies a_k = \dfrac{P_n^{(k)}(x_0)}{k!}$.

> [!abstract] Формула Тейлора для многочлена
> $$\boxed{P_n(x) = \sum_{k=0}^{n} \frac{P_n^{(k)}(x_0)}{k!} (x - x_0)^k}$$
> Данное равенство является **точным** для любого многочлена степени $n$.

## 2. Формула Тейлора для произвольной функции

Пусть функция $f(x)$ имеет в некоторой окрестности точки $x_0$ непрерывные производные до $(n+1)$-го порядка включительно. Тогда её можно приблизить многочленом Тейлора степени $n$ с погрешностью, описываемой **остаточным членом** $R_n(x)$:

$$
f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!} (x - x_0)^k + R_n(x).
$$

### 2.1. Формы записи остаточного члена

> [!abstract] 1. Остаточный член в форме Лагранжа
> $$R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!} (x - x_0)^{n+1},$$
> где $c$ — некоторая неизвестная точка, лежащая строго между $x_0$ и $x$.
>
> **Назначение:** позволяет оценить **абсолютную величину погрешности** вычислений (например, при расчёте значений $\sin x$ в калькуляторе с заданной точностью $10^{-9}$ через оценку максимума модуля $(n+1)$-й производной).

> [!abstract] 2. Остаточный член в форме Пеано
> $$R_n(x) = o\bigl((x - x_0)^n\bigr) \quad \text{при } x \to x_0.$$
>
> **Назначение:** показывает **скорость стремления погрешности к нулю** при $x \to x_0$ (остаток стремится к нулю быстрее, чем последнее слагаемое многочлена). Применяется при вычислении пределов и раскрытии неопределённостей.

## 3. Ряды Тейлора и Маклорена

Если функция $f(x)$ бесконечно дифференцируема в окрестности точки $x_0$, то при $n \to \infty$ многочлен Тейлора переходит в **ряд Тейлора**:

$$
f(x) = \sum_{k=0}^{\infty} \frac{f^{(k)}(x_0)}{k!} (x - x_0)^k.
$$

При $x_0 = 0$ получаем **ряд Маклорена**:

$$
f(x) = \sum_{k=0}^{\infty} \frac{f^{(k)}(0)}{k!} x^k.
$$

> [!important] Достаточное условие сходимости ряда к самой функции
> Ряд Тейлора сходится к функции $f(x)$ на отрезке $[a, b]$ (то есть $\lim_{n \to \infty} R_n(x) = 0$), если все производные функции $f^{(n)}(x)$ на этом отрезке **ограничены в совокупности** одним и тем же числом $M$:
> $$\bigl|f^{(n)}(x)\bigr| \le M \quad \forall n \in \mathbb{N},\; \forall x \in [a, b].$$

### Таблица стандартных разложений по формуле Маклорена (знать наизусть)

| Функция | Разложение в ряд Маклорена | Область сходимости |
|---|---|---|
| $e^x$ | $1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \dots + \dfrac{x^n}{n!} + \dots = \displaystyle\sum_{k=0}^{\infty} \frac{x^k}{k!}$ | $x \in (-\infty, +\infty)$ |
| $\sin x$ | $x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dfrac{x^7}{7!} + \dots = \displaystyle\sum_{k=0}^{\infty} (-1)^k \frac{x^{2k+1}}{(2k+1)!}$ | $x \in (-\infty, +\infty)$ |
| $\cos x$ | $1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \dots = \displaystyle\sum_{k=0}^{\infty} (-1)^k \frac{x^{2k}}{(2k)!}$ | $x \in (-\infty, +\infty)$ |
| $\ln(1 + x)$ | $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \dfrac{x^4}{4} + \dots = \displaystyle\sum_{k=1}^{\infty} (-1)^{k-1} \frac{x^k}{k}$ | $x \in (-1, 1]$ |
| $(1 + x)^\alpha$ | $1 + \alpha x + \dfrac{\alpha(\alpha - 1)}{2!} x^2 + \dots + \dfrac{\alpha(\alpha - 1)\cdots(\alpha - n + 1)}{n!} x^n + \dots$ | $x \in (-1, 1)$ |

> [!tip] Связь с таблицей эквивалентных бесконечно малых
> Первые члены разложений Маклорена при $x \to 0$ дают известные эквивалентности:
> - $e^x - 1 \sim x$ (точнее: $e^x = 1 + x + \frac{x^2}{2} + o(x^2)$);
> - $\sin x \sim x$ (точнее: $\sin x = x - \frac{x^3}{6} + o(x^3)$);
> - $1 - \cos x \sim \frac{x^2}{2}$ (точнее: $\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} + o(x^4)$);
> - $\ln(1 + x) \sim x$ (точнее: $\ln(1 + x) = x - \frac{x^2}{2} + o(x^2)$).

## 4. Приложение производных: исследование функций на экстремум

> [!abstract] Теорема Ферма (необходимое условие экстремума)
> Если функция $f(x)$ имеет локальный экстремум в точке $x_0$ и дифференцируема в этой точке, то её производная в точке $x_0$ равна нулю:
> $$\boxed{f'(x_0) = 0}$$

> [!warning] Необходимость $\neq$ достаточность
> Равенство $f'(x_0) = 0$ является **только необходимым**, но **не достаточным** условием экстремума.
> - Точки, в которых $f'(x_0) = 0$ (или производная не существует), называются **критическими (стационарными)**.
> - Например, для функции $f(x) = x^3$ в точке $x_0 = 0$ производная $f'(0) = 0$, но экстремума нет (это точка перегиба).
